# Little Lemon React Native App

A React Native mobile application for the Little Lemon restaurant, built with Expo.

## Features

- Onboarding with first name and email
- Persistent user profile
- Home screen with Little Lemon hero section
- Search menu items
- Filter menu by categories
- Combined search and category filtering
- SQLite local menu database
- Profile editing
- Logout functionality
- Stack navigation

## Technologies

- React Native
- Expo
- React Navigation
- Expo SQLite
- AsyncStorage

## Getting Started

### Install dependencies

npm install

### Start the application

npx expo start

### Run on Android

npx expo start --android
